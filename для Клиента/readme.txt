ЭЛЕКТРОННАЯ СИСТЕМА УЧЁТА УСПЕВАЕМОСТИ (ЭСУУ)
РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ


1. ОБЩИЕ СВЕДЕНИЯ

Электронная система учёта успеваемости (ЭСУУ) предназначена для автоматизации
контроля оценок и посещаемости учеников в учреждениях среднего общего и начального
образования. Система предоставляет веб-интерфейс для четырёх категорий пользователей:
администратор, учитель, ученик, родитель. Каждая категория имеет свой набор функций,
определяемый ролью.

Ключевые возможности системы:
- 9 типов оценок (ВПР, контрольная работа, диктант, ответ у доски и др.)
- Четвертная система (1-4 четверти)
- Классный руководитель с доступом к ведомости класса
- Родительский дашборд с диаграммами и авто-уведомлениями
- Полный аудит действий пользователей
- Экспорт данных в Excel и Word
- Массовый импорт справочников из Excel


2. ТРЕБОВАНИЯ К РАБОЧЕМУ МЕСТУ ПОЛЬЗОВАТЕЛЯ

Для серверного компьютера:
- ОС Windows 10/11 (64-разрядная)
- Процессор от 2.0 ГГц
- ОЗУ от 4 ГБ
- Свободное дисковое пространство от 500 МБ
- Python 3.10 или выше

Для клиентских рабочих мест:
- Веб-браузер: Google Chrome, Mozilla Firefox или Microsoft Edge последних версий
- Доступ к серверу системы по локальной сети


3. УСТАНОВКА И ЗАПУСК СИСТЕМЫ

3.1. Запуск единого скрипта (start.bat)

Дважды щёлкните start.bat в корневой папке проекта. Откроется меню:

STUDENT PERFORMANCE SYSTEM

1. Запустить СЕРВЕР
2. Запустить КЛИЕНТ
3. Установить библиотеки
4. Добавить Python в PATH
5. Выход

Пункт 1 - запускает сервер и открывает страницу входа в браузере.
Пункт 2 - подключается к уже запущенному серверу (на этом же или другом ПК).
Пункт 3 - устанавливает все необходимые библиотеки из requirements.txt.
Пункт 4 - добавляет Python в системный PATH (если не был добавлен при установке).
Пункт 5 - выход.

3.2. Раздельный запуск (сервер + клиент на разных ПК)

На ПК-сервере:
1. Запустите start_server.bat
2. Дождитесь сообщения "Сервер запущен" и запишите IP-адрес
3. Убедитесь, что брандмауэр разрешает входящие соединения на порт 8001

На ПК-клиенте:
1. Скопируйте папку frontend и файл start_client.bat
2. Запустите start_client.bat
3. При первом запуске введите IP-адрес сервера (сохраняется для последующих запусков)
4. Браузер откроет страницу входа

3.3. Первоначальная настройка

1. После запуска сервера откройте Swagger UI: http://IP_сервера:8001/api/docs
2. Зарегистрируйте администратора через POST /api/auth/register
3. Войдите в админ-панель и создайте классы, учителей, учеников, предметы


4. РУКОВОДСТВО АДМИНИСТРАТОРА

Администратор управляет всей справочной информацией системы. После входа отображается
главная панель со сводной статистикой и быстрым доступом к разделам.

4.1. Управление классами
1. Перейдите в раздел "Администрирование", вкладка "Классы"
2. Введите номер класса (1-11) и букву (А, Б, В...)
3. При необходимости выберите классного руководителя из списка учителей
4. Нажмите "Создать"
5. Для удаления нажмите "Удалить" в строке таблицы и подтвердите действие

4.2. Регистрация учителя
1. Вкладка "Учителя"
2. Заполните поля: Логин, Email, Пароль, ФИО
3. Укажите преподаваемый предмет (например, "Математика")
4. Нажмите "Добавить"

4.3. Регистрация ученика
1. Вкладка "Ученики"
2. Заполните поля: Логин, Email, Пароль, ФИО
3. Выберите класс из выпадающего списка
4. При необходимости укажите логин родителя для автоматической привязки
5. Нажмите "Добавить"

4.4. Создание предмета
1. Вкладка "Предметы"
2. Введите название предмета
3. Выберите учителя и класс
4. Укажите четверть (1-4) и количество часов
5. Нажмите "Добавить"

4.5. Создание родителя
1. Вкладка "Родители"
2. Заполните поля: Логин, Email, Пароль, ФИО
3. В списке учеников выберите одного или нескольких (Ctrl+клик)
4. Нажмите "Добавить"

4.6. Массовый импорт данных
На вкладках "Классы", "Ученики", "Учителя", "Предметы", "Родители" доступна
загрузка из Excel:

1. Нажмите "Выберите файл" и укажите файл .xlsx
2. Нажмите "Загрузить"
3. Система покажет результат: количество созданных и пропущенных записей
4. Таблица автоматически обновится

Форматы Excel-файлов:

Классы: Название | Номер | Буква
Ученики: ФИО | Логин | Email | Пароль | Класс
Учителя: ФИО | Логин | Email | Пароль | Предмет
Предметы: Название | ФИО учителя | Класс | Четверть | Часы
Родители: ФИО | Логин | Email | Пароль | ФИО ученика

Важно: перед импортом учеников должны быть созданы классы; перед импортом
предметов - учителя и классы.

4.7. Просмотр логов
1. Вкладка "Логи"
2. Используйте фильтры: Роль, Пользователь, Действие, период дат
3. Нажмите кнопку поиска для применения фильтров
4. Для экспорта - кнопки Excel или Word

4.8. Просмотр пользователей и смена пароля
- Вкладка "Пользователи" - список всех зарегистрированных пользователей с ролями
- Кнопка "Сменить пароль" в боковом меню - выберите пользователя, введите новый
  пароль (не менее 6 символов), нажмите "Сохранить"


5. РУКОВОДСТВО УЧИТЕЛЯ

Учитель выставляет оценки, отмечает посещаемость и формирует отчёты.

5.1. Выставление оценки
1. Перейдите в раздел "Оценки"
2. Выберите ученика из списка (ФИО и класс)
3. Выберите предмет (только закреплённые за вами)
4. Выберите оценку (2-5) и тип контроля:
   Экзамен, Практическая работа, ВПР, Контрольная работа,
   Самостоятельная работа, Диктант, Тест, Ответ у доски, Домашняя работа
5. При необходимости введите комментарий
6. Нажмите "Добавить"

5.2. Удаление оценки
В таблице оценок нажмите кнопку с иконкой корзины и подтвердите удаление.

5.3. Отметка посещаемости
1. Перейдите в раздел "Посещаемость"
2. Выберите ученика, предмет, статус и дату
3. Нажмите "Отметить"
4. Обновится таблица, круговая диаграмма и карточки статистики

5.4. Формирование ведомости
1. Перейдите в раздел "Ведомость"
2. Выберите класс и предмет
3. При необходимости задайте период дат
4. Нажмите "Показать"
5. Для экспорта - кнопки Excel или Word

5.5. Экспорт данных
На страницах "Оценки" и "Посещаемость" доступны кнопки экспорта в Excel и Word.
Файл будет скачан браузером автоматически.


6. РУКОВОДСТВО УЧЕНИКА

Ученик просматривает только свою успеваемость и посещаемость.

6.1. Просмотр оценок
- Раздел "Оценки" - таблица с предметом, оценкой, типом контроля, датой и комментарием
- Фильтрация по предмету и периоду дат
- Экспорт в Excel или Word

6.2. Просмотр посещаемости
- Раздел "Посещаемость" - таблица записей и круговая диаграмма
- Экспорт в Excel или Word

6.3. Смена пароля
Кнопка "Сменить пароль" на главной странице.


7. РУКОВОДСТВО РОДИТЕЛЯ

Родитель контролирует успеваемость ребёнка. После входа автоматически попадает
на страницу "Мой ребёнок".

Доступная информация:
- ФИО и класс ученика
- Средний балл
- Таблица оценок с типами контроля
- Таблица посещаемости
- Круговая диаграмма посещаемости

Автоматические уведомления:
- Наличие неудовлетворительных оценок (2)
- Более трёх пропусков занятий

Экспорт данных: кнопки "Оценки Excel/Word" и "Посещаемость Excel/Word".


8. ЗАВЕРШЕНИЕ РАБОТЫ

Для выхода нажмите "Выйти" в боковом меню. Система удалит данные сеанса
и перенаправит на страницу входа.


9. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И ИХ РЕШЕНИЕ

"Неверный логин или пароль" - проверьте раскладку клавиатуры и Caps Lock.
При утере пароля обратитесь к администратору.

"Failed to fetch" - проверьте, запущен ли сервер. Убедитесь, что IP-адрес
в config.js указан верно.

Ошибка при экспорте - проверьте подключение к серверу, повторите попытку.

Не отображаются данные - нажмите кнопку фильтрации или обновите страницу (F5).

Ошибка при импорте Excel - проверьте формат файла по образцу под кнопкой
загрузки. Убедитесь, что связанные данные (классы, учителя) уже существуют.

Сервер не запускается - проверьте, не занят ли порт 8001. При необходимости
измените порт в run.py.

Клиент не подключается - убедитесь, что ПК в одной сети. Отключите брандмауэр
или разрешите порт 8001.

Python не найден - запустите start.bat, пункт 4 "Добавить Python в PATH"
или установите Python с python.org.


10. ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ

Архитектура: трёхзвенная (Frontend, FastAPI, SQLite)
API эндпоинтов: 32
Таблиц базы данных: 8 (users, students, teachers, classes, subjects, grades,
attendance, audit_logs)
Экспорт: Excel (XLSX) и Word (DOCX)
Импорт: Excel (XLSX) - классы, ученики, учителя, предметы, родители
Аутентификация: JWT-токены (срок действия 24 часа)
Хеширование паролей: bcrypt
Год разработки: 2026
