# Электронная система учёта успеваемости

Дипломный проект по специальности 09.02.07 «Информационные системы и программирование».

## О проекте

Веб-приложение для автоматизации учёта оценок и посещаемости учащихся. Система поддерживает четыре роли пользователей: администратор, учитель, ученик и родитель. Каждая роль имеет свой набор функций, определяемый правами доступа.

## Ключевые возможности

- 9 типов оценок с аналитикой по формату усвоения материала (ВПР, контрольная, диктант, ответ у доски и др.)
- Четвертная система вместо семестров — адаптация под школьный стандарт
- Классный руководитель с быстрым доступом к ведомости класса
- Родительский дашборд с диаграммами посещаемости и авто-уведомлениями о проблемах
- Полный аудит действий пользователей с фильтрацией и экспортом
- Массовый импорт справочных данных из Excel
- Экспорт в Excel и Word по всем разделам системы
- Тёмная тема оформления

## Технологии

- **Backend:** Python 3.12, FastAPI, SQLAlchemy ORM, Pydantic
- **База данных:** SQLite (не требует отдельного сервера)
- **Frontend:** HTML5, CSS3, JavaScript (vanilla JS, без фреймворков)
- **Аутентификация:** JWT-токены (24 часа), хеширование паролей bcrypt
- **Документация API:** Swagger UI (автоматическая генерация)
- **Экспорт:** OpenPyXL (Excel), python-docx (Word)
- **Визуализация:** Chart.js (круговые диаграммы посещаемости)

## Состав системы

- 32 эндпоинта REST API, сгруппированных в 7 модулей
- 8 таблиц базы данных с обеспечением целостности
- 8 страниц веб-интерфейса с динамическим меню по ролям
- Запуск в один клик через систему bat-скриптов

## Быстрый старт

**Вариант 1. Локальный запуск (сервер + клиент на одном ПК):**
1. Установите Python 3.10 или выше
2. Запустите `start.bat` в корне проекта
3. Выберите пункт 1 «Запустить СЕРВЕР»
4. Браузер откроется автоматически

**Вариант 2. Раздельный запуск (сервер и клиент на разных ПК):**
1. На ПК-сервере запустите `start_server.bat` — он покажет IP-адрес
2. На ПК-клиенте запустите `start_client.bat` — введите IP-адрес сервера
3. Браузер откроется и подключится к серверу

Дополнительные возможности меню `start.bat`:
- Пункт 3 — установка всех библиотек из requirements.txt
- Пункт 4 — добавление Python в системный PATH
